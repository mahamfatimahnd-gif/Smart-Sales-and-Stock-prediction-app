# Smart-Sales-and-Stock-prediction-app 
The Sales and Stock Prediction and Management System is a smart inventory management application designed for retail businesses. It allows users to manage products, record sales, and monitor stock levels in an efficient and organized way. The system also uses machine learning to analyze past sales data and predict future sales trends.

Based on these predictions, the application provides intelligent stock recommendations to help users avoid overstocking or running out of inventory. It consists of a Flutter-based frontend for user interaction and a Flask-based backend for data processing and prediction.
